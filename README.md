## نظرة عامة
المشروع هو جزء من مشروع تخرج يهدف إلى بناء نظام تعليمي متكامل للأمن السيبراني. تتيح المنصة للمتعلمين دراسة الثغرات الأمنية الشائعة (مثل SQL Injection و XSS) من خلال مقارنة الأكواد الضعيفة والآمنة، واجتياز اختبارات قصيرة للتأكد من الفهم. **لا يمكن تخطي أي درس**؛ إذ يعتمد النظام على منطق `LOCKED → ACTIVE → COMPLETED` لضمان تعلم تراكمي فعال.

يحتوي النظام على ثلاثة أدوار:
- **زائر** يرى الصفحة الرئيسية وصفحات التسجيل.
- **متعلم** يتابع الدروس ويتقدم في المسار التعليمي.
- **مشرف (أدمن)** يدير الدروس (إضافة، تعديل، حذف).

## الميزات الرئيسية
- 📚 **دروس تفاعلية**: محتوى نظري وأكواد برمجية خاطئة وآمنة معروضة جنبًا إلى جنب مع تمييز الصيغة (Syntax Highlighting).
- 🔒 **نظام قفل ذكي**: لا يمكن الوصول إلى الدرس التالي قبل إتمام الدرس الحالي واجتياز فحصه بنجاح.
- ✅ **فحوصات فورية**: أسئلة اختيارية بعد كل درس مع ردود فورية (نجاح/فشل) وتحديث تلقائي للتقدم.
- 🤖 **مساعد ذكي (Chatbot)**: زر عائم يظهر للمتعلمين، ينشئ جلسات محادثة مع خادم الذكاء الاصطناعي للمساعدة والدعم.
- 📊 **لوحة تحكم مشرف**: إدارة كاملة للدروس (CRUD) مع حقول مخصصة للكود والفحص.
- 🎨 **واجهة عصرية**: تصميم متجاوب مع حركات سلسة (Framer Motion) وهويات لونية (أزرق، زمردي، سماوي) مستوحاة من مفاهيم الأمان والتكنولوجيا.
- 🔐 **حماية المسارات**: مصادقة عبر JWT، حراس مسارات (Guards) تمنع الوصول غير المصرح به، وتسجيل خروج تلقائي عند انتهاء الجلسة.
- ⚡ **أداء ممتاز**: تحميل كسول (Lazy Loading) للصفحات، وتجميع سريع عبر Vite.

## التقنيات المستخدمة
| التقنية | الاستخدام |
|----------|------------|
| **React 18** | بناء واجهة المستخدم (Components, Hooks) |
| **Redux Toolkit** | إدارة الحالة المركزية (Auth, Lessons, Progress, Chat) |
| **React Router v6** | التوجيه وحماية المسارات (ProtectedRoute) |
| **Tailwind CSS** | تصميم عصري وسريع باستخدام كلاسات جاهزة |
| **Axios** | طلبات HTTP مع Interceptors لإرفاق JWT |
| **Framer Motion** | حركات وانتقالات سلسة (للصفحة الرئيسية والبطاقات) |
| **React Syntax Highlighter** | عرض الأكواد بتنسيق احترافي (خلفيات خضراء/حمراء) |
| **Vite** | أداة بناء سريعة ودعم ممتاز لـ Tailwind |

## المتطلبات الأساسية
- Node.js (v18 أو أعلى) و npm مثبتين على الجهاز.
- خادم خلفي (Backend) يعمل على `http://localhost:5000` (أو أي منفذ آخر يتم تعديله في ملف `.env`).
- متصفح حديث (Chrome, Firefox, Edge).

## خطوات التشغيل
1. **انسخ المستودع**  
   ```bash
   git clone https://github.com/username/cybersec-academy-frontend.git
   cd cybersec-academy-frontend
   ```
   ثبّت التبعيات

```bash
npm install
```

اكتب المتغير التالي (مع تعديل المنفذ إن لزم):

```text
VITE_API_BASE_URL=http://localhost:5000
```
ملاحظة: نضع العنوان الأساسي للخادم بدون /api لضمان صحة الروابط في الجدول أدناه.

شغّل وضع التطوير

```bash
npm run dev
```
سيتم فتح المتصفح على http://localhost:5173.

بناء للإنتاج

```bash
npm run build
npm run preview   # لمعاينة البناء محليًا
```
